# NEON SPINS v3

Projeto completo de desenvolvimento/homologação com:
- frontend responsivo
- API Express
- banco SQLite persistente
- cadastro/login demo
- carteira de créditos virtuais
- giros e histórico
- bônus demo
- painel ADMIN
- usuários, jogos, transações e estatísticas
- autenticação por sessão demo

## Iniciar
Requer Node.js 20+.

```bash
npm install
npm start
```

Acesse:
- Plataforma: http://localhost:3000
- Admin: http://localhost:3000/admin.html
